# ElFoxo — демоверсия сайта

Демонстрационный сайт детских головных уборов и аксессуаров в стиле премиального минималистичного магазина.
Статический HTML/CSS/JS: без сборки и без зависимостей.

> **Важно.** Все изображения — демонстрационные SVG-иллюстрации, созданные для макета
> (`scripts/generate-images.mjs`). Это не фотографии товаров ElFoxo. Товары, цены, размеры и тексты —
> демонстрационные. Реальные контакты и коммерческие условия бренда не указаны. Оплата не подключена,
> персональные данные не собираются (корзина и избранное хранятся только в `localStorage` браузера).

## Запуск локально

Нужен Node.js 18+.

```bash
npm start            # или: node scripts/serve.mjs 8080
```

Откройте в браузере: http://localhost:8080

Подойдёт и любой статический сервер, например `python3 -m http.server 8080 -d public`.

## Что есть на сайте

- Шапка с логотипом, навигацией по разделам, избранным и корзиной; мобильное меню.
- Главный экран с баннером и кнопкой «Смотреть коллекцию».
- Категории (клик фильтрует каталог).
- Каталог из 16 демо-товаров: фильтры, сортировка, смена цвета на карточке, избранное.
- Карточка товара: цвета, размеры, количество, добавление в корзину; ссылка вида `#product-<id>`.
- Корзина (выезжающая панель) с изменением количества; «Оформить заказ» показывает сообщение о демо-режиме.
- Блок новой коллекции, раздел о бренде, преимущества, шаги заказа, подбор размера по обхвату головы.
- Подвал с навигацией и ссылкой на официальный сайт elfoxo.ru.

## Структура

```
public/                 ← всё, что публикуется
  index.html
  assets/css/styles.css
  assets/js/products.js ← данные демо-каталога (заменить на реальные)
  assets/js/app.js      ← логика интерфейса
  assets/img/           ← демо-иллюстрации
  _headers, robots.txt  ← заголовки Cloudflare Pages, запрет индексации
scripts/
  generate-images.mjs   ← генератор иллюстраций (npm run images)
  serve.mjs             ← локальный сервер
wrangler.toml           ← конфигурация Cloudflare Pages
```

Чтобы поставить настоящие фотографии: положите файлы в `public/assets/img/products/`
и поправьте функцию `imageOf` / данные в `products.js`.

## Публикация на Cloudflare Pages (когда будет разрешение)

Вариант 1 — через Git: Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git,
выбрать репозиторий, **Build command:** пусто, **Build output directory:** `public`.

Вариант 2 — из терминала:

```bash
npx wrangler login
npm run pages:deploy   # wrangler pages deploy public --project-name elfoxo-demo
```

Сайт закрыт от индексации (`robots.txt`, `X-Robots-Tag`), т.к. это демоверсия.
